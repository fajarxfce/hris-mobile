# Coherent original and replacement evidence

The existing Group and actual Company history repositories can now read original events and up to
sixteen requested replacement operations under one authenticated source revision. Each operation
retains all of its zero to128 aliases; an absent operation is an explicit empty result, and overflow
fails without returning partial proof. Default snapshots request no extra operation queries.

Inputs are copied before suspension. Original identity, current edits, eligibility and redaction
are returned only while the final source checkpoint still matches. A changed operation-index
checkpoint uses the existing preparation-conflict signal. The owning repositories retain key and
account lifetimes; the existing indexed evidence reader performs raw acquisition. No new repository
chain, transport, timer or permanent observer is introduced. Group and Company data remain in their
actual physical namespaces even when coordinates coincide.

operation order, separate physical copies, accepted/rejected/redacted edits, old no-query behavior,
source changes, key loss, restart, joined cancellation, caller mutation, account replacement,
sixteen requested operations,128aliases and explicit129overflow. Existing history/evidence contracts
and app bindings remain. Focused51/full16719 pass, preserving every16687 preceding test identity plus
32 JVM/browser executions. New Apple compilation passes; actual Apple execution is separate.

sender/hash and these coherent facts. ACK or command absence cannot clear the optimistic preview.
