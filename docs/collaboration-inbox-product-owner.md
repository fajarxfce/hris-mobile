native runtime readiness, token age and selected HR company. A domain observation coordinates
current session, locally retained root and directory admission directly. Missing or failed facts
withdraw the owner. Account/root handoffs withdraw it before waiting for replacement admission;
positive results recheck current admission, root and final session after suspended reads.
Confirmed denial remains gated until admitted restoration, and late cancellation cannot grant an
obsolete owner. Normal source completion also withdraws ownership. No SDK or API acquisition is
part of this observation.

The application owner serializes collection and cancels/joins the previous repair before starting
a replacement. Equal owners cannot restart failed work; no timer retry was added. One lazy child
of ApplicationCollaborationLifetime starts on every platform and is included in closeAndJoin.
Observer/repair exceptions cannot stop native ownership. Diagnostics contain categories and
failure kinds, never user identifiers or message content. Feature DI binds the admitted observer;
application DI binds the process owner and existing finite repair worker.

unchanged token rotation, slow replacement admission, denial/restoration, changes during suspended
reads, cancellation, completion, collection serialization and joined replacement. Three desktop
application-lifetime additions cover start-once, native independence and joined exception/cleanup
behavior. Two actual SQLite additions exercise the application factory and real session clear/
restore, retaining history across reopen without opening a native SDK. All17506 prior test
identities remain. Apple test compilation is included; actual new Apple execution remains open.
