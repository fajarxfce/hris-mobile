# Admitted Original recovery reference reading

A retained Company history may belong to a different device from the currently installed client
and may have no primary queue task. `ReadCollaborationSpaceOriginalKeyReferences` admits that
explicit history against its current native source, registered Original Company and immutable
room metadata, then reads one finite page of local references. It does not acquire message
content, acknowledge references, advance the global pass or invoke provider/key APIs.

The existing encrypted incoming checkpoint receives one independent recovery request through
the existing repository and pure request policy. Absence creates no record. An active pass keeps
its cursor and captured reference boundary while later generations coalesce. Replaying an already
completed generation stays idle. A changed section must be confirmed through exact local readback,
including checkpoint family and nonregressing counters, even when the write response was lost.
Each invocation performs at most one write within a five-second cancellable lifetime.

A pending query reads at most sixteen references after the captured recovery cursor. The result
must keep the same active pass; a later requested generation may coexist, while a known request
cannot disappear. Concurrent primary appends cannot extend the captured boundary. Returned event
lists are copied. Empty Flow is a failure. An empty page is attempted-page evidence; a later owner
must still prove indexed EOF before acknowledging progress.

Admission is checked around metadata, registration, progress, write, readback and query operations.
Account, native-session, source, registration or metadata replacement and confirmed denial reject
late results, including after a local commit. Previously owned facts do not expire with preparation
credentials and do not depend on the currently selected company. No primary task is fabricated.

Twenty-nine new common domain cases exercise those boundaries, replay/coalescing, finite pages,
malformed inputs, lost/lying writes, contention, regressions, cancellation after commit and reopen,
deadlines and old credentials. Existing policy/storage tests and both application graph checks
remain controls. One initial compile attempt failed before tests because three cursor/limit
assertions needed explicit nullable Pair element types. Only those new assertion declarations
were corrected; the failed candidate remains recorded and production source was unchanged.
