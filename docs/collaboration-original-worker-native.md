# Canonical incoming worker native fixture

The fixture now starts the real application source collector, adopts the retained canonical
registration and observes its durable source before invoking the registered worker. Company
history is read through its physical Company/device coordinates; metadata indexes are checked
before content reads. No duplicate Published history is inserted.

Six existing native controls pass on the normal SDK8 proof APK, including encrypted edits/deletes,
offline process reopening, lost acknowledgement and native key receipt confirmation. The full
worker test remains open: its first provider page exposes content, but duplicate alias/inventory
work still prevents completion within the unchanged four-turn bound. Same-boot inspection is
read-only and emits counts/flags, never identifiers, content or credentials. Temporary diagnostic
production logs were restored and are not part of this change.

No phone APK, live server, schema or production behavior changes are included.
