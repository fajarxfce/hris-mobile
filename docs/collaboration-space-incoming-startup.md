# Local incoming startup observation

The domain observer combines the current native parent, retained organization root,
registration, completed bootstrap and directory admission. Its pure policy matches the
registration, operation, device, platform and provider. It publishes only stable local
coordinates, without credentials. Ordinary token age and journal revisions do not create
another signal. Failed storage stays a failure; current denial remains enforced.

The owner stream precedes one final bootstrap `flatMapLatest` boundary. A regression with
a suspended consumer originally received an old bootstrap after root removal. The final
owner boundary now cancels that pending emission and all previous subscriptions. Tests also
cover account/native-parent replacement, disposal, malformed/oversized inventories, pending
or superseded bootstrap, readmission and offline observation. Readmission removes the old
denial revision under the existing storage contract; no redundant revision field was added.

The focused gate passes 156 tests and the full gate passes 10,940 tests, including 19 new
domain cases on JVM and Chromium. The previous 10,902 case identities remain. Source and
library fingerprints stayed fixed. This observer performs no network, SDK, scheduling or
clock acquisition. No application subscriber is connected yet; automatic startup still
requires its owning application collector and native acceptance. Apple execution of this
increment remains separate from the earlier native-worker CI. All 54 PRD groups remain open.
