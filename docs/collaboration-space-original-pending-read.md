# Original incoming pending references

The Original incoming owner can now read one bounded page of locally retained pending references. It derives Company access and the original physical device from the captured runtime/room, confirms the current typed Pending task and installed source, and reads the existing Company traversal index. A Group registration receipt never substitutes for the original physical device; Company progress keeps provider=null.

A read requests at most16 references after the retained pending cursor. The finite pendingThrough boundary trims later provider appends out of the current pass; one final empty page is allowed. Regressing revisions/reference counts, changed generation/provider frame/wave/seek, and changed task/source are rejected. The event list is detached before subsequent suspended checks. Missing or superseded tasks return no work; an owned missing checkpoint remains explicit empty progress for the separate recovery owner.

The five-second invocation checks Group directory denial, account/native/source ownership, immutable Original metadata and registered LEGACY provenance around storage I/O.
